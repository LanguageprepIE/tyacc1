What is Pythagoras?

In a right-angled triangle, the square of the hypotenuse (the longest side) equals the sum of the squares of the two shorter sides.

a2 + b2 = c2
Here, c is the hypotenuse.

Worked Example

Find the hypotenuse when the two short sides are 6 and 8.

  1. Use the formula: a² + b² = c²
  2. Compute: 6² + 8² = 36 + 64 = 100
  3. So c² = 100 → c = √100 = 10
Answer: c = 10

Common Mistakes

  • Using Pythagoras for non-right triangles — it only works for right-angled triangles.
  • Mixing up which side is c — c is always the side opposite the right angle (the longest side).
  • Forgetting to take the square root at the end when solving for a side.
